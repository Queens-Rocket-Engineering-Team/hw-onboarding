# QRET Hardware Onboarding
> Intro to ECAD and QRET Hardware Dev. Practices

This repository is dedicated for development and file storage for the **Intro to ECAD** workshop. More details can be found on the **Notion**, under `Workshops & Unboarding`. 

The workshop focuses on the engineering process behind hardware development:

**Requirements** -> **Architecture** -> **Schematics** -> **PCB Layout** -> **Design Review** ...

And all of the sub-sections in between. 

--- 
Members will build IC-breakout-boards interfacing with:
* Power Systems
* I/O
* A dedicated IC
---

## Get Started

1. To get started, create a separate development branch. 
- Use the following name convention: `dev/name-name/board-name`
    - For example: `dev/jeevan-andrew/imu-board`
- You will design on this branch --- this is a similar pattern on how we design Avionics hardware.
